# Материалы для разговора с родителем

По PARENT-MODE-D-004 от 2026-09-29 пользователь разрешил оставить темы
ненаполненными. Тексты не создаются автоматически, отсутствие каталога
не должно блокировать запуск backend и остальные ручки.

`GET /v1/parent-materials` — публичный read-only каталог без deviceId, питомца
и зависимости от готовности оценок. Ответ содержит `schemaVersion=1`, непустой
`contentVersion`, `publicationStatus` и `skills`:

- `UNPUBLISHED`: `skills=[]`; штатное отсутствие текстов, не ошибка сети.
- `PUBLISHED`: ровно одна запись FIN-01…FIN-12, каждая содержит `skillId`,
  `learningGoal`, `story`, `replaceWithParentStory`, пять непустых
  `conversationStarters`, `parentTakeaway`, `researchBasis`,
  непустой список HTTPS `researchSources`.

Backend использует `src/infra/api/parents/data/materials.json`; отсутствие
файла означает UNPUBLISHED. Некорректный существующий файл даёт контролируемый
503 на ручках материалов, не мешает запуску приложения и другим API.
Legacy `GET /api/parents/{petId}` сохраняет демонстрационные данные; при
UNPUBLISHED все прежние поля материалов присутствуют с пустыми строками/списками
и `materialsAvailable=false` у каждого навыка. Демо-данные в игру не переносятся.

Android содержит такой же ненаполненный каталог в
`app/src/main/assets/parents/materials.json`. Он доступен без сети. После PIN
отдельно от оценок запрашивается обновление через общий HTTP rate-limit.
Валидная remote-редакция заменяет bundled-копию в памяти процесса; после
перезапуска до обновления снова используется bundled-копия. Повреждённый
ответ или ошибка сети сохраняют предыдущий каталог с пояснением.
UNPUBLISHED явно отображается как «материалы пока не опубликованы».

Опубликованный каталог отображается по точным FIN-кодам: цель, история,
предложение своего примера, вопросы, вывод, обоснование, источники. Материалы
не заменяют реальные оценки навыков и локальные игровые свидетельства.
Room, игровой snapshot, история и экономика не изменяются; квесты и
политика mastery остаются отдельными задачами.
