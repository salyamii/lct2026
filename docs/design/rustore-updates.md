# Обновления приложения через RuStore

Подключён `ru.rustore.sdk:appupdate:10.5.1`, версия хранится в
[каталоге зависимостей](../../gradle/libs.versions.toml). Официальный Maven-репозиторий
в [settings.gradle.kts](../../settings.gradle.kts) ограничен группой `ru.rustore.sdk`.
[Документация SDK](https://www.rustore.ru/help/sdk/updates/kotlin-java/10-5-1).
Сценарий утверждён в [RUSTORE-D-001](decisions.md).

## Поведение

- После загрузки основного интерфейса выполняется проверка при переходе в RESUMED.
  Intro-видео, загрузочный экран и ошибка чтения сохранения исключены.
- При доступной версии открывается стандартный диалог RuStore FLEXIBLE.
  Пользователь может отказаться или продолжить играть во время скачивания.
  Возврат из диалога и пересоздание Activity не повторяют предложение скачивания.
- Готовность отслеживается слушателем SDK и повторной проверкой после возврата
  в foreground, в том числе после перезапуска процесса.
- Диалог «Обновление готово» предлагает «Установить» или «Позже».
  Установка вызывает `completeUpdate(FLEXIBLE)`; приложение перезапускается.
  «Позже» скрывает предложение до следующего foreground.
- В фоне слушатель освобождается, результат отменённой проверки не открывает UI.
- Отсутствие RuStore, отсутствие авторизации, недоступная сеть и ошибки SDK
  не блокируют приложение. Диагностика: logcat, тег `RuStoreUpdates`.

Обновление не вызывает игровые команды и не меняет Room-схему. Родительская
Activity не запускает собственный сценарий обновлений. Платежи, push и отзывы
не входят в эту интеграцию.

## Ручная проверка перед публикацией

Проверить на устройстве с актуальным RuStore и авторизованным пользователем.
Для полноценного обновления подготовить доступную в RuStore более новую сборку
с тем же applicationId `ru.nksk.lctapp`, совместимой подписью и большим
`versionCode`. SDK не заменяет публикацию APK в консоли RuStore.
Текущий versionCode задаётся в [app/build.gradle.kts](../../app/build.gradle.kts);
повышать его при выпуске следующей версии.

1. Убедиться, что без RuStore и без доступного обновления игра открывается.
2. Отклонить скачивание: игра остаётся доступна, диалог сразу не повторяется.
3. Принять скачивание, свернуть и вернуть приложение: после завершения появляется
   предложение установки; новая загрузка параллельно не запускается.
4. Выбрать «Позже», затем вернуться из фона и подтвердить установку.
5. Проверить повторный запуск на новой версии и сохранённый игровой прогресс.
6. Проверить отмену/ошибку установки и возможность повторной попытки.

Автоматическая проверка по текущей настройке проекта ограничена сборкой,
компиляцией тестов и lint. Эти шаги не подтверждают работу установленного RuStore
на устройстве; приложение и тесты агент не запускает.
