# Balanced checklist - 2026-10-18

`menu_action_tasks_v4` is a built-in `image_gen` edit of the
[narrow v3 checklist](../energy-scroll-2026-10-18/menu_action_tasks_v3.png).
It gives the upright parchment an intermediate width, with an approximately
2:3 visible paper face, while retaining the square canvas and blank bottom
name plaque. The result was visually reviewed before import. This is generated
game artwork, not a Figma export. The v3 resource and source remain available.

The exact editing prompt is retained in [prompts.json](prompts.json).
The caption remains native UI text on the wooden plaque; no lettering is
painted into the image. The proportion change belongs to the generated artwork,
not to a stretched or cropped runtime bitmap.

The [PNG original](menu_action_tasks_v4.png) was copied unchanged from
`exec-5d93e6a5-1f27-482d-b045-5a28d2b0ee50.png` in the Codex generated-images
directory. Its complete 1254 x 1254 canvas, alpha and transparent margins are
preserved. The original file in that directory is unchanged.

The Android resource is lossless exact WebP, method 6, without resizing,
cropping, repositioning, color changes or background removal. Decoded PNG and
WebP dimensions and every RGBA byte were verified identical.

File sizes, SHA-256 hashes, alpha bounds, source/reference hashes and converter
version are recorded in [manifest-entries.json](manifest-entries.json) and the
main [asset manifest](../../manifest.json). The RGBA hash includes the width
and height as two big-endian 4-byte integers before the decoded pixel bytes.
