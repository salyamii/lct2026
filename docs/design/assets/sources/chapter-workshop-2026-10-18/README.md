# Верстак и лямка

Созданы встроенным imagegen 2026-10-18 для CHAPTER-GAMES-D-002.
Точные запросы и уточнение для прозрачного полотна: [prompts.json](prompts.json).
Это сгенерированные материалы, не новые экспорты Figma.

| Ресурс | Назначение | Полотно |
| --- | --- | --- |
| `story_game_workbench_surface` | Деревянная поверхность для обеих сцен | 1024 × 1536 |
| `story_game_strap_patch` | Основа и свободный конец лямки | 1024 × 1536, RGBA |

PNG-оригиналы сохранены рядом. Runtime-файлы находятся в
`app/src/main/res/drawable-nodpi/<resource>.webp`.
Полотно и альфа сохранены полностью, без обрезки, перекраски и масштабирования.
Pillow 10.2.0: `lossless=True`, `exact=True`, `method=6`; размеры и все
RGBA-байты после обратного декодирования совпадают с исходниками.
SHA-256, RGBA SHA-256, размер и alpha bounds записаны в
[manifest.json](../../manifest.json).

В лямке разделительная линия проходит на y=.53. Нижняя часть сдвигается на
−.23 высоты в Compose; оригинальный растр не разрезается и не растягивается.
Точки шва x=.40/.60, y=.39/.47 находятся внутри перекрытия. Нить, игла,
направляющие и узел рисуются кодом поверх материала.
