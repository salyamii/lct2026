# Предметы неожиданных событий - оригиналы Figma, 2026-09-26

Из 25 исходных карточек неожиданных событий проверены все видимые IMAGE fills,
включая видимость родительских узлов. Перенесены 22 оригинальных предмета для
ремонта/очистки: рюкзаки, промокшая карта, верёвка, штатив, линзы, фонарь, верстак,
картографическая пластина, компас, шестерня, ключ, свиток, журнал, звёздная пластина,
рычаг, крыша, ящик, кольцо и разбитое окно. Это исходные изображения соответствующих
неисправностей из Figma, не подмена исправными вещами из коллекции.

Каждый PNG 1254 × 1254 совпадает по SHA-1 с активным imageHash. WebP переведён
lossless exact, полное полотно и альфа сохранены без ресайза и обрезки. Скрипт
`import_assets.py` проверяет точное совпадение RGBA до записи в общий манифест.
`provenance.json` сохраняет родительскую карточку, ID/название предмета, размеры
узла и хеш оригинала; `manifest-entries.json` - итоговые размеры, хеши и пути.

Два ранее перенесённых рисунка переиспользуются: колесо из 2164:86 и фонарь из
2164:133. У карточки болезни 2164:139 нет видимого лекаря или предмета: видимы фон
2164:141 и фиксированный больной лис 2164:179. Последний меняет возраст/образ
героя и имеет повязки/костыль; им не подменяется текущий персонаж из сохранения.

`story-source-audit.json` - отдельная проверка 13 указанных в каталоге исходных
FigJam-карточек оставшихся сюжетных сцен. В каждом узле SECTION содержит один
RECTANGLE и 12 TEXT, image fills отсутствуют. Это подтверждённое отсутствие в
этих исходных узлах, а не утверждение о содержимом всего Figma-файла. N3.ACCESS
и N5.TRAVEL созданы как программные связки сценария и не имеют исходного узла.
