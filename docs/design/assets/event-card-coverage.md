# Иллюстрации событий - 2026-09-26

Пользователь сообщил, что персонажи и предметы не появляются на части карточек.
Причина реализации: новый каталог передавал `character = null`, а прежний адаптер
разрешал только два ключа Смотрителя. При пустом `scene` отсутствовал даже фон.

`core/ui/game/EventSceneArtwork.kt` задаёт привязки по постоянному ID события,
включая версии дел `:balance-v2`. Его используют карточки и миниигры. Это слой
отображения: он не меняет состав персонажей истории, владение предметами, выборы
или последствия. `DayEventScene` получает текущий образ питомца из сохранения;
фон и главный NPC/предмет показываются отдельно от меняющегося героя.

| Группа | Покрытие |
| --- | --- |
| 13 коротких дел | У всех есть предмет или подходящий NPC, включая первоначальные и повторно сбалансированные версии |
| 69 сюжетных сцен | Для 65 задан NPC/предмет; первое вступление сохраняет отдельное превью Ночи наблюдений |
| 25 неожиданных событий | У 24 показан исходный предмет; карточка болезни показывает текущего питомца |
| 8 действующих покупок и старая кепка | Сохранены соответствующие изображения предложений и аксессуаров |

Оставшиеся сцены без отдельного предмета показывают текущего питомца:

- G2.05: внутреннее кольцо башни; G5.11: цепочка ответивших маяков.
- N3.ACCESS: программная связка о техническом отсеке, отдельный арт завала
  в проверенном каталоге не найден.
- N5.TRAVEL: программный переход по дороге, текущего героя на тропе достаточно.
- `figma-2164-139-v2`: в исходнике 2164:139 нет видимого лекаря. Есть только фон
  2164:141 и фиксированный больной лис 2164:179 с костылём/повязками. Он не
  подменяет сохранённый возраст, цвет и образ текущего питомца.

У карточек с пустым ключом места нет проверенных уникальных интерьеров башни
или станции. Используется иллюстрация главы/тропы как контекст; она не объявлена
новым интерьером. Для неожиданных событий теперь используются 22 оригинальных
изображения конкретных неисправностей, а не исправные предметы из коллекции.
Колесо и фонарь переиспользуют уже проверенные оригиналы своих исходных карточек.

## Прозрачность предметного слоя

Все 22 исходных предмета неожиданных событий и пять покупочных предметов уже
имели альфу. В интерфейсе их закрывали кремовые подложки: они убраны из
`DayEventScene` и карточки покупки. В сюжетных минииграх исключены непрозрачные
листы коллекции `collection_*`; для карт и приборов используются прозрачные
оригиналы. Хроноскоп в G2.12 теперь отдельный предмет, а не прямоугольная сцена
с верстаком. Имеющиеся NPC сохраняются при добавлении сюжетных привязок.

[42 исходных предмета, проверка 90 foreground-ресурсов и воспроизводимый импорт](sources/story-objects-transparent-2026-09-26/README.md).
Иллюстрированные страницы предметов в инвентаре сохранены; это отдельный вид
артефактов, а не слой предмета поверх локации.
