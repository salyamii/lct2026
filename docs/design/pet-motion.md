## Текущая реализация

`PetMotion` использует исходную картинку персонажа и одну локальную фазу:
четыре вдоха по 4,2 секунды в цикле 16,8 секунды, небольшое покачивание.
Масштаб по вертикали меняется максимум на 1,2%, горизонтальное смещение —
на 0,3% холста, поворот — на 0,65°. Отдельного вертикального перемещения нет.
Опора преобразования находится у ног; тень и привязка карты неподвижны.
Для особых состояний, кроме HAPPY, интенсивность снижена до 35%.

Чтение фазы происходит в `graphicsLayer`, без покадровой рекомпозиции меню.
Цикл существует только в RESUMED, Preview показывает исходную позу.
Персонаж не имеет обработчика нажатий; описание для доступности сохранено.
Coil, ограниченный кэш, асинхронное декодирование, общий painter фона и
ленивый список дел сохранены. Длительность переходов не менялась.

## Отложенный прототип

Вне репозитория сохранён локальный архив
`pet-animation-prototype-20260922-aad11a/prototype.zip` с исходным кодом,
ресурсами, PNG, промптами, манифестом и SHA-256 каждого файла.
Рядом находится README с указаниями по точечному восстановлению.

- Приветствие: 1,1 секунды, приседание, подскок, приземление, искорки и тень.
- Моргание: 220 мс через 3–6 секунд, две небольшие области глаз с мягкими
  масками поверх исходного тела. Медный окрас, четыре возраста, базовый образ,
  бандана и рюкзак; для двух бандан есть индивидуальные смещения.
- Общие старые глазные патчи визуально не подошли: пользователь отметил
  несовпадение цвета и эффект наложения. Сохранённые новые кадры подготовлены
  по каждому возрасту отдельно; для остальных окрасов/особых образов нужны
  собственные проверенные источники.
- [Четыре новых кадра в Figma](https://www.figma.com/design/bAod1cKtTX9Q8omQ067q3q/?node-id=2825-2).
- [Старые глазные патчи в Figma](https://www.figma.com/design/bAod1cKtTX9Q8omQ067q3q/?node-id=2821-2).

При возвращении переносить части прототипа точечно: общие файлы в архиве
сохранены для контекста, их полная замена может отменить последующие изменения.
Проверки — сборка и компиляция тестов; приложение запускает пользователь.
