# Голос родительских текстов

Обновлено: 2026-10-19. Действует для родительского режима детского приложения,
отдельного родительского приложения (`lct26-parentsapp`) и серверных текстов
бэкенда (`assessmentReason`, материалы `materials.json`).

Родительские тексты читает живой человек после рабочего дня. Пишем так, как
объяснили бы устно: просто, тепло, без канцелярита и без разработческого
жаргона. Правила дополняют ограничения из
[skill-explanations.md](../backend/skill-explanations.md): тексты описывают
отмеченные игровые действия, не назначают уровень навыка и не выдают один
случай за привычку.

## Правила

1. **Никакой машинной лексики.** Не «сервер», «получено», «эпизод»,
   «наблюдение», «не удалось получить». Вместо них: «интернет», «пришло»,
   «ситуация в игре», «числа».
2. **Активный залог и живые глаголы.** «Оценки приходят из интернета», а не
   «обновляются через интернет»; «оценено 3 из 12», а не «оценки получены
   для 3 из 12».
3. **Одно предложение — одна мысль.** Короткое предложение лучше точного
   канцелярского. До ~12 слов, если смысл не теряется.
4. **Разнообразие зачина.** «Пока…», «Ещё…», «Не удалось…» не должны начинать
   два соседних текста на экране.
5. **Неуверенность — по-человечески.** Вместо «пока неизвестно, учтёт ли это» —
   «увидим в следующих играх», «станет ясно позже». Но не обещаем и не
   додумываем: неизвестное остаётся неизвестным.
6. **Честность важнее утешения.** Трудности не прячем и не смягчаем до лжи.
   Пояснение «это не значит, что ребёнок не умеет» — где уместно.
7. **Числа — для объяснения, не для отчётности.** Одна-две цифры в тексте
   причины статуса; не превращаем текст в таблицу.
8. **Обращение** — к родителю на «вы», глаголами-инструкциями («нажмите»,
   «обсудите»), без «пожалуйста» и без восклицательных знаков, кроме редких
   тёплых моментов (завершение квеста).
9. **Термин только если без него никак.** «Оценка», «навык», «копилка» — можно;
   «счётчик», «проекция», «политика», «fallback» — нет.
10. **Ё пишем всегда** («ребёнок», «придёт») — во всех трёх кодовых базах.
11. **Плейсхолдеры и пустые состояния объясняют, что делать дальше.** Не просто
    «нет данных», а «пока нет — вот что появится и когда продолжить».
12. **Одинаковые формулировки в обоих родительских клиентах.** Общая строка
    пишется один раз и копируется во второе приложение дословно.

## Проверка

Перед коммитом прочитать изменённый экран вслух. Если фраза так не
произносится — переписать. Примеры:

| Плохо | Хорошо |
| --- | --- |
| «Серверные числа пока не получены» | «Числа из интернета ещё не дошли» |
| «Подробное основание оценки пока недоступно» | «Объяснение статуса пока не готово» |
| «Успешных ситуаций: 2, из них без игровых подсказок: 2; с трудностями: 0» | «У ребёнка минимум два успеха без подсказок — и успехов больше, чем трудностей» |
| «Для вывода не хватает сведений об условиях выбора» | «Мало видно, как именно шёл этот выбор, поэтому вывода пока нет» |
