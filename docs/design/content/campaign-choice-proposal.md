# Общая история и свободный выбор больших целей

Дата: 2026-09-20. Статус: **редакционный разбор адаптации**.

По D-103 реализован рабочий каталог. [Точное поведение, отличия и границы](../campaign-choice.md)
имеют приоритет над иллюстративными вариантами ниже. Этот документ не заменяет
авторскую выгрузку и не является самим исполняемым каталогом.

Разобраны все 60 карточек из [авторской выгрузки кампании](campaign-lore.figma.json):
пять глав, 41 CORE и 19 OPTIONAL. Дополнительно использованы
[экранные тексты первой главы](chapter-1-screens.figma.json).
Авторские тексты, их ID и условия в этих источниках не изменены.
Новые реплики и способы участия ниже — предложения, а не материал Figma.

Пользователь подтвердил [D-101 и D-102](../decisions.md): сначала доступны три
большие цели; после выполнения одной добавляется следующая; всего целей пять.
Финал главы требует полного комплекта текущей выбранной цели, причём это может
быть любая доступная цель. По D-104 стартуют наблюдения, подготовка к башне
и дом; карта добавляется после первого проекта. Финальная цель разрешена
после завершения остальных четырёх.

## 1. Как соединить четыре части

**История задаёт порядок открытий. Цель задаёт личный проект. Карточка показывает
конкретную сцену. Планировщик выбирает следующую доступную сцену по фактам.**

| Часть | Что определяет | Пример |
| --- | --- | --- |
| Общая история | Что герой уже узнал и какое открытие следует дальше | Метка → отвечающая башня → Свиток → Хроноскоп |
| Выбранная цель | На какой комплект сейчас копит игрок | Наблюдения, подготовка похода или восстановление дома |
| Карточка | Действие, его условия и результат; подходящий контекст реплик | Свой телескоп или участие в общей Ночи наблюдений |
| Дневной план | Когда доступная сцена попадёт между делами, нуждами и случайностями | Продолжение лора после починки колеса, а не просто «карточка №6» |

Для общего финала главы одновременно нужны:

1. Предыдущие обязательные сюжетные события пройдены, необходимые факты известны.
2. Собран комплект текущей выбранной цели и необходимые вещи всё ещё принадлежат игроку.
3. Выполнены условия самой сцены: место, доступ, необходимые действия, питание и силы.

Покупка последней вещи выполняет только второй пункт. Она не открывает карточку,
не телепортирует героя и не раскрывает тайну следующей главы.
Просмотр последней сюжетной подсказки выполняет только первый пункт.
Если комплект ещё не собран, продолжаются обычная жизнь и доступные дела.
До выбора любой цели сохраняется обычная жизнь без лора по D-082: новое общее
вступление предлагается после выбора, при явном продолжении дня. Разделение
сюжета и конкретного проекта не означает автоматического лора без выбора цели.

Проект прохождения: одна выбранная цель сопровождает текущую главу; её комплект
засчитывается для одного перехода. После финала игрок выбирает следующий проект.
Это способ реализации D-102, а не подтверждённое правило переключения целей
посреди главы. Повторно использовать один завершённый проект для всех глав нельзя.
Потеря вещи не должна заново выдавать уже полученное сюжетное открытие.

## 2. Выбор целей и смысл завершения

Предлагаемый состав стартовой тройки — первые три проекта из исходника:

- «Ночь наблюдений»: собрать собственный комплект для наблюдений.
- «Экспедиция к погасшей башне»: подготовить личное снаряжение для будущего похода.
- «Дом исследователя»: собрать материалы и оборудование для восстановления дома.

После первого выполненного проекта предлагается «Карта королевства».
Пятая цель — «Большая экспедиция». Её условие доступности разобрано в разделе 8.
Состав витрины подтверждён D-104; проект башни в UI называется «Подготовка к башне».

**Комплект и сюжетное действие различаются.** Собранное снаряжение для башни ещё
не означает, что башня исследована. Покупка карты не открывает неизвестный регион.
Восстановленный жилой дом не означает, что прочитан его запертый технический архив.
Так ранняя покупка не раскрывает будущие события и не создаёт циклических условий.

Описание цели в витрине до открытия соответствующих фактов должно быть без спойлеров.
Например, раннее описание подготовки похода говорит о старой северной башне,
а не о Свитке или Хроноскопе. Для карты обещаем собственный атлас, а не координаты
последней станции. После открытия сведений меняется контекст описания.

Четыре части первой цели и цены 24 / 36 / 90 / 30 остаются по D-088.
Новые цены, награды, преимущества дорогих комплектов и расходы маршрутов здесь
не назначаются. Указанные в исходнике 200, 180 и резерв 40 не становятся
утверждённым балансом остальных целей через этот документ.

### Одна сюжетная сцена, разные обстоятельства

Для G1.12 общий результат всегда один: герой узнаёт о сети Смотрителей путей.

| Выбранный проект | Предлагаемая связка перед общим открытием |
| --- | --- |
| Наблюдения | Собственный комплект готов. Герой приносит его на Ночь наблюдений. |
| Подготовка похода | Снаряжение готово. Смотритель приглашает сначала сверить маршрут и сигналы на общих наблюдениях. |
| Дом | Материалы собраны. Смотритель приглашает героя на наблюдения; замеченный на доме знак связывается с общей загадкой только после нужных открытий. |

Ночная сцена использует личный комплект, если он есть, иначе — общий прибор
обсерватории. Общий прибор не становится предметом в инвентаре и не отмечает
личную цель наблюдений выполненной. Герой действительно участвует в сцене.
Это новая сценарная возможность, которую нужно утвердить до реализации.

Реплика о завершённом личном проекте может входить в ту же финальную карточку.
Она не требует дополнительного окна «готово» или дополнительного шага дня.
Переход сохраняется после явного действия; далее — главное меню с обычным
коротким подтверждением, без автоматического запуска следующей истории.

## 3. Собранная история в пяти актах

Порядок актов сохраняется при любом порядке личных проектов.
Ниже — редакционный пересказ и предложенные связки, а не замена авторских карточек.

### Акт I. Башня, которая отвечает

Герой знакомится с обсерваторией и выбирает первый личный проект. Смотритель
готовит общую Ночь наблюдений. Выполняя дело на Причале, герой замечает знак
на ящике. Такой же знак находится на старой пластине в обсерватории.
После очистки появляется загадка о трёх ответах в одном свете.

Починка телеги приводит к старой карте. Архив, дорожный пост или запасная
подсказка в журнале объясняют порядок цветных огней. Герой настраивает малый
телескоп, и башня отвечает. На общих наблюдениях метки складываются в сеть
маршрутов. Герой узнаёт имя Смотрителей путей и понимает, зачем идти к башне.

Финал ждёт собранного первого выбранного проекта. Если это не комплект
наблюдений, используется приглашение и общий прибор. Причина экспедиции
появляется из найденного сигнала, а не из названия выбранной финансовой цели.

### Акт II. Свиток второго пути

Смотритель организует исследование башни после подтверждённого сигнала.
Игрок выбирает следующий личный проект и параллельно помогает подготовить
выход. Разрушенный мост требует реального решения: ремонта или доступного
обхода. Отказ «позже» не считается прохождением моста.

За мостом герои находят протокол входа. Известный порядок огней открывает
механизм, а рабочий источник света позволяет пройти внутрь. Журнал показывает,
что башню закрыли намеренно. Свиток и ключ приводят обратно в нижний зал
обсерватории. Там раскрывается Хроноскоп — прибор сравнения последствий одного
изменённого решения, а не машина предсказаний.

Если игрок копит на дом или карту, он участвует в исследовании как помощник
Смотрителя с групповым оснащением. Доступ к нему требует отдельной сцены
подготовки; свет, маршрут и действия не возникают из факта чужой покупки.
Личное экспедиционное снаряжение при этом не выдаётся и цель не выполняется.
Финал раскрывает Хроноскоп после находок и комплекта текущего проекта.

### Акт III. Мастерская, которая хранила правила

На детали Хроноскопа находится номер старой мастерской. Это новая связка к дому,
заменяющая обязательное назначение «теперь твоя цель — дом». Если дом уже
восстановлен, речь идёт о закрытом служебном отсеке. Если ещё нет — об осмотре
технической части с разрешения Смотрителя; жилищная цель остаётся отдельной.

Тико помогает разобраться в устройстве мастерской. Под верстаком обнаруживается
калибровочная деталь, а журнал объясняет: сохрани исходные условия и меняй только
одно решение. Линза под крышей доказывает, что здесь проверяли приборы сети.
В ящиках картографа находятся старые маршруты, которых нет на современных картах.

Общее открытие финала — назначение станции и необходимость помощи картографа.
Собственный восстановленный дом получает личный эпилог, когда действительно
выполнен этот проект. Тико может быть знакомым помощником до этого;
постоянное спутничество не выдаётся автоматически за осмотр чужой мастерской.

### Акт IV. Место, которое убрали с карты

Луна приходит исследовать найденные маршрутные фрагменты. Она работает на
собственном или общем картографическом столе, если игрок ещё не собрал личный.
Архивная копия показывает намеренно удалённую дорогу. На горном указателе
герой видит два маршрута с разными затратами. Хроноскоп помогает сравнить их.

Основные находки дают достаточно фрагментов для продолжения без обязательного
прохождения OPTIONAL-карточек. Между фрагментами проявляется пустая область.
Пограничный маяк указывает туда, где должен находиться последний узел сети.

Общий финал фиксирует исследовательскую схему и направление экспедиции.
Личный атлас и оборудование картографа остаются покупаемой целью. Если она
выполнена раньше, новые сведения дополняют существующий атлас; неизвестная
область не открывается повторно и не считается знакомой задним числом.

### Акт V. Почему Смотрители остановили сеть

После выяснения направления герои идут к дальнему узлу. Выбор пути может
менять расходы и дорожные события, но оба доступных маршрута приводят
к релейной станции. В её журнале прямо сказано, что Хроноскоп сравнивает
возможные последствия и ничего не обещает.

Центральный архив объясняет закрытие сети: после шторма дороги изменились,
а старые расчёты перестали соответствовать миру. Герои обновляют данные и
находят последнюю станцию. Тико может помочь с реле, если условия его участия
выполнены; без необязательной помощи путь остаётся через карту Луны.

Последнее послание предлагает спрашивать «что изменилось и почему», сохраняя
решение за путешественником. Финал требует пройденного акта и комплекта
текущей цели по D-102. По D-104 «Большая экспедиция» строго последняя.
Завершение истории не выдаёт покупные части: игрок собирает все проекты сам.

## 4. Новые связки: черновики реплик

Все реплики в этом разделе написаны для предложения. Имя подставляется через
`{petName}`. Буквы N — локальные обозначения обсуждения, не production event ID.

**N1. Общее знакомство с обсерваторией вместо автоматического выбора цели.**

> Смотритель готовит Ночь наблюдений и зовёт всех, кому интересно небо.
> «Приходи, {petName}. А свой большой проект выбери сам: можно собирать прибор,
> готовиться к походу или обустраивать дом. Со старыми загадками разберёмся вместе».

**N2. Приглашение, если текущая цель — не наблюдения.**

> «Твой комплект готов. Перед следующим делом загляни вечером в обсерваторию.
> Ты помог найти эти знаки — теперь давай посмотрим, что они означают».

Контекст «комплект готов» допустим только при фактическом выполнении цели.
Внутри сцены общий телескоп назван явно. Нельзя показывать личный прибор,
если соответствующие предметы не куплены.

**N3. Участие в исследовании башни с другим личным проектом.**

> «Башня ответила нам обоим. Для общего выхода я подготовлю приборы и свет,
> а ты помоги проверить дорогу. Твой собственный проект подождёт нашего возвращения».

Это предложение контекста групповой подготовки, не бесплатное приобретение
набора и не готовые правила стоимости путешествия. Сцена подготовки должна
предшествовать проверке наличия рабочего света в G2.06.

**N4. Причина посетить дом после Хроноскопа.**

> Тико поворачивает деталь: «Видишь номер? Такой же выбит на двери старой
> мастерской. Если прибор обслуживали там, инструкция могла остаться в доме».

Если дом уже отремонтирован, следующая реплика: «Жилую часть мы привели в порядок,
но этот служебный шкаф ещё не открывали». Если Тико пока не знаком, первую
реплику произносит Смотритель; знакомство с Тико происходит в G3.04.

**N5. Осмотр дома, который ещё не является готовым личным проектом.**

> «Весь дом сегодня не восстановить. Начнём с мастерской: нам нужно безопасно
> открыть верстак и понять, к какому прибору относятся старые детали».

Осмотр и ограниченная работа не должны автоматически отмечать купленными
материалы для полного восстановления дома. Безопасный доступ оформляется
реальным событием, а не предположением в тексте финала.

**N6. Карта Луны и личный атлас.**

> «Пока положим находки на мой стол, — говорит Луна. — Общую схему соберём здесь.
> А в собственный атлас ты потом сможешь перенести всё, что мы проверим».

При наличии своего стола и атласа используется другой контекст: «Добавим новый
слой в твою карту». В обоих вариантах новые факты возникают после исследования.

**N7. Третий обязательный фрагмент карты.**

> Под листом архивной карты сохранилась оборотная копия. Луна совмещает её
> с горным фрагментом: «Вот граница ещё одного участка. Теперь видно,
> что пустое место между дорогами слишком ровное».

Предлагаемое добавление в обязательную сцену после G4.07: даёт третий
исследовательский фрагмент, если его ещё нет. Это сюжетная информация,
не покупаемая часть личного атласа. OPTIONAL-берег и лес дают дополнительные
маршруты и контекст, но не становятся скрытой обязательной покупкой/поездкой.

**N8. Финал без необязательного ремонта реле.**

> «Связь ещё не восстановлена повсюду. Но теперь мы знаем, почему сеть
> остановили, и отмечаем только проверенные дороги. Это и будет началом новой карты».

Если реле и маяки реально восстановлены, остаётся авторский образ возвращающихся
огней. Текст о восстановлении всей сети не показывается при пропущенном ремонте.

## 5. Что делать с каждой из 60 исходных карточек

CORE остаются обязательными для соответствующего открытия; OPTIONAL сохраняют
свои окна доступности и обогащают сюжет. Номер G обозначает источник, а не
обязательный номер выбранного проекта. Исполняемая адаптация потребует отдельных
версий определений. Здесь перечислены изменения смысла и условий, не новые цены.

| Источник | Роль | Предлагаемая адаптация |
| --- | --- | --- |
| G1.01 | CORE | Разделить общее приглашение в обсерваторию и выбор личной цели. N1; цель выбирается на своём экране. |
| G1.02 | CORE | Оставить знак после реального дела на Причале; сделать доступным при любом личном проекте. |
| G1.03 | CORE | Оставить находку пластины и её фактическую очистку. Очистка не равна просмотру находки. |
| G1.04 | OPTIONAL | Сохранить журнал грузов, доверие и окно до следующего открытия. |
| G1.05 | CORE | Сохранить расшифровку после очистки и условие вечерней сцены. |
| G1.06 | CORE | Сохранить старую карту после ремонта колеса; ремонт доступен независимо от выбранной цели. |
| G1.07 | OPTIONAL | Сохранить эмблему службы; отсутствие карточки не блокирует имя Смотрителей в общем финале. |
| G1.08 | CORE | Сохранить схему линз и доступ к дорожному посту после необходимых фактов. |

## 6. Обнаруженные разрывы в исходных условиях

Эти проблемы есть уже в выгрузке; свободный выбор целей делает их заметнее.

1. **OPTIONAL-порядок цветов.** G1.09 необязательна, но далее нужен
   clue_light_order. Запасная мини-подсказка упомянута в тексте G1.10/11;
   её исполнение должно действительно записывать этот факт.
2. **Недостаточно обязательных фрагментов.** G4.08 требует минимум три,
   а явно обязательные архив и горы дают два. N7 закрывает разрыв при пропуске
   OPTIONAL-берега и леса. Нужно также отдельно определить обещанные в G4.02
   «четыре региона», не превращая необязательные сцены в скрытые обязательные.
3. **Финал заявляет восстановление сети.** Сам ремонт реле/маяков OPTIONAL.
   N8 различает понятое устройство сети и реально восстановленную связь.
4. **Факт есть в условии, но нет явного действия-поставщика.** Для helped_dock,
   wheel_repaired, bridge_passed, tower_access_reached, доверия, вечерних сцен,
   доступа к шкафам и перемещений нужны конкретные события/действия.
   Нельзя отмечать их автоматически при входе в главу.
5. **Разные смыслы карты.** kingdom_map_goal_complete и kingdom_map_complete
   должны различать личный комплект и исследовательское знание. Для финального
   маршрута нужна именно проверенная схема и её происхождение.
6. **Резерв.** Обязательные 40 в G5.01 исходника пока не являются правилом
   финансового движка. Это нельзя незаметно превратить в отдельный кошелёк,
   заблокированные деньги или новый денежный критерий завершения цели.

## 7. Крупные узлы реализации

Нужна существенная адаптация сюжетного слоя, но не новый движок дня.

- **Каталог целей:** доступные проекты и очередь открытия отдельно от номера акта.
  Экран показывает варианты, а не `goals.first()`.
- **Продвижение истории:** пройденные обязательные сцены и полученные факты.
  Условия общего лора не содержат проверку «выбрана именно цель дома/карты».
  Целевые личные сцены такую проверку сохраняют.
- **Планировщик:** выбирает доступные основные и необязательные сцены, затем
  смешивает с повседневными. Не ставит недоступную сцену в начало так, чтобы
  она перекрыла обычный день. Перенос сохраняет уже назначенные экземпляры.
- **Шаблон карточки:** варианты текста/медиа выбираются по реальным фактам,
  предметам и знакомству с NPC. Вариант оформления не создаёт новую награду
  и не считается повторным прохождением того же открытия.
- **Финал главы:** проверяет общий сюжет и комплект выбранного проекта;
  отмечает переход один раз и возвращает игроку выбор следующей цели.
  Это надо отвязать от одного `nextChapterId` с заранее назначенным проектом.

Существующие фабрика экземпляров, команды, проверки голода/сил, питание,
сроки дел и расчёты покупок применимы дальше. Подробная схема хранения,
совместимость старых сохранений и миграции — отдельная задача реализации;
этот документ их не определяет и не меняет текущую базу.

### Предусловия: принадлежность главе и доступность — разные вещи

`chapterId` может обозначать авторскую группу карточек. Исполняемая доступность
задаётся конкретными требованиями; одна принадлежность к главе не доказывает,
что у героя есть свет, он знает код или дошёл до башни.

Предлагается три области событий:

- **Общие:** еда, предложения дел, покупки и неприятности. Обычно не требуют
  номера главы; конкретная поломка требует соответствующей вещи/места.
- **Основная история:** текущий акт и реальные сюжетные предпосылки. В проекте
  сохраняется порядок общих открытий; ID личной цели здесь не нужен.
- **Личный проект:** выбор конкретной цели, владение её частями и нужные факты.
  Такие сцены дают контекст проекта и могут встретиться в разных актах.

Внутри условия нужны сочетания «всё перечисленное», «хотя бы один вариант»
и «ещё не произошло». Это предполагаемый формат авторского контента,
не уже реализованный API или необходимость скрипта на каждую карточку.

| Карточка | Пример необходимых условий |
| --- | --- |
| Знак на ящике G1.02 | Акт I; выполнено подходящее дело на Причале; открытие ещё не пройдено. |
| Вход в башню G2.06 | Достигнут вход; известен порядок огней; подготовлен личный или групповой свет; пройдены предыдущие основные сцены. |
| Финал акта II G2.12 | Найдены Свиток и ключ; открыт доступ в нижний зал; собран комплект текущей выбранной цели; финал ещё не пройден. |
| Поломка личного фонаря | Фонарь действительно принадлежит герою и участвует в текущем действии/маршруте. Сам акт II не гарантирует владения. |
| Личная сцена готового дома | Выбран/завершён проект дома согласно правилам этой сцены; необходимые части куплены; реплики учитывают знакомство с Тико и знание Хроноскопа. |

Для разовых сцен проверяется история конкретного открытия; для повторяемых
дел нужны правила повторения, а не вечный запрет после первого выполнения.
Питание, силы и актуальный баланс проверяет общий движок при действии ещё раз.
Планировщик пользуется теми же требованиями, чтобы не предлагать заведомо
непроходимую сцену. Он не должен хранить второй независимо вычисленный набор
разрешений, расходящийся с командой выполнения.

### Можно ли менять порядок самих глав

**В исходном лоре зависимости есть во всех пяти главах, не только у Хроноскопа.**

| Связь | Почему перестановка исходных глав нарушает историю |
| --- | --- |
| I → II | Сигнал объясняет поход, известный порядок огней используется при входе в башню (G1.11 → G2.06). |
| II → III | Кольцо под верстаком уже называется деталью Хроноскопа, а журнал объясняет знакомый прибор (G2.12 → G3.05/07). |
| III → IV | Из мастерской приходят фрагменты, которые изучает Луна (G3.10/12 → G4.01). |
| IV → V | Маяк и схема дают направление дальней экспедиции; без них неизвестно, куда идти (G4.12 → G5.01/09). |

Ранний ремонт дома возможен, раннее знание назначения кольца — только после
открытия Хроноскопа. Ранний личный атлас возможен, найденные координаты последней
станции — только после исследования карты. Это различие позволяет свободно
выбирать проекты без перестановки общих сюжетных актов.

Другой, более объёмный вариант — нелинейное исследование мира: посетить дом
раньше, найти неопознанное кольцо, а после Хроноскопа получить отдельную сцену
узнавания; встретить Луну раньше и дать ей другое происхождение первых карт.
Тогда сцены зависят преимущественно от фактов, а не номера акта. Понадобятся
новые карточки первого знакомства/узнавания, альтернативные источники зацепок
и проверка каждого допустимого порядка. Просто ослабить `chapterId` или убрать
предыдущее событие недостаточно. **Этот вариант не принят и не является
описанной выше адаптацией с общей последовательностью актов.**

## 8. Открытые решения и проверка вариантов

### Пятая цель и конечное число предложений

Пять целей не позволяют бесконечно сохранять три доступных варианта после
каждого выполнения. После исчерпания новых проектов витрина закономерно сужается.

По D-104 выбран вариант со строго финальной пятой целью: она показана заранее,
но выбор разрешён после завершения первых четырёх. До неё число доступных
вариантов сужается до двух, затем одной цели. «Открыта», «выбрана», «комплект
собран» и «проект завершён в финале главы» остаются разными состояниями.

Открыты переключение незавершённого проекта и полноценные механики спутников.
Временные цены и расходы согласованы в D-105/D-106. Текущие адаптации личных
эпилогов и условных карточек описаны в [реализации](../campaign-choice.md).

### Сценарии, которыми проверять согласованность

| Случай | Ожидаемая связность проекта |
| --- | --- |
| Дом выбран первым | Жилой проект завершается, но Хроноскоп ещё не назван. Сигнал и сеть раскрываются в акте I; технический архив дома — в акте III. |
| Подготовка башни выбрана первой | Комплект готов, но вход в башню не открыт. Общие наблюдения раскрывают сеть; поход происходит в акте II. |
| Наблюдения выбраны третьими | Сигнал не показывается как новая находка повторно. Личный комплект завершает проект, общая история находится в акте III. |
| Карта собрана до акта IV | Есть личные принадлежности/атлас. Неизвестные координаты появляются только после изучения фрагментов. |
| Комплект готов раньше лора | День продолжается, нужные находки проходят по порядку; финал не перескакивает вперёд. |
| Лор готов раньше комплекта | Финал ждёт покупки, доступны обычные события и заработок. Ожидание не назначает новую цель само. |
| Пропущены все OPTIONAL | Есть основной способ получить код, решить маршрут, собрать минимум фрагментов и найти последнюю станцию. |
| Нет дома/личного стола/личного фонаря | Нужные общие средства вводятся конкретной сценой доступа; не появляются в личном инвентаре и не выполняют чужую цель. |
| Пропущен ремонт реле | Последнее послание доступно, финальный текст не утверждает восстановление маяков. |
| Питомец устал перед финалом | Финал и остальной план переносятся по действующим правилам, покупки и открытия сохраняются. |
| Игрок вернулся в приложение | Не повторяются вступления, знакомство, выдача фактов и переход уже пройденной главы. |

Для полноценной реализации понадобится проверить все допустимые порядки
выбора целей после утверждения правил витрины, а не только эти примеры.
