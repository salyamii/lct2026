# Карта и Compose Preview — 2026-09-20

Карта подключена к приложению: кнопка карты в меню открывает `feature/map`.
Выбор доступной локации сохраняется в Room, затем пользователь возвращается в меню.
Открыть `app/src/debug/java/ru/nksk/lctapp/feature/map/ui/LocationMapPreview.kt`
в Android Studio, выбрать debug-вариант и режим Split / Design.
Есть варианты с выбранным городом и мастерской, компактный, альбомный и крупный текст.
В Interactive Preview нажатие меняет только выделение точки.
Оболочка превью хранит ID выбранного места через `rememberSaveable`, чтобы
восстанавливать выбор при пересоздании Activity, включая смену конфигурации.
Сам `LocationMapScreen` не владеет выбором: получает ID и callback снаружи.
В приложении выбор восстанавливается из `GameState.locationScene` после
реконфигурации и перезапуска; debug-оболочка хранит только выбор превью.
Решение соответствует [гайду Android о сохранении UI-состояния](https://developer.android.com/develop/ui/compose/state-saving),
проверенному через `android docs search` / `android docs fetch`.

В проекте доступны все 14 уже импортированных изображений из
[набора Figma](https://www.figma.com/design/bAod1cKtTX9Q8omQ067q3q/?node-id=2144-9):
9 мест, включая 5 пар день/вечер. Исходные WebP и alias города перечислены в
[каталоге](assets/catalog.md#locations); повторный импорт не требуется.
Названия взяты из набора ассетов. Соответствие старым названиям точек карты
и сюжетным главам пока не установлено.

Фон — новая иллюстрация, сгенерированная встроенным imagegen по уточнению
пользователя 2026-09-20 в стиле первоначального концепта. Все девять мест
изображены отдельно; области нажатия и подписи остаются нативными элементами Compose.
Это предложенная география для превью, не граф сюжетного прохождения.
[Исходник и происхождение](assets/sources/map_adventure_day.md).
Lossless WebP сохраняет полный холст 853 × 1844; фон отображается с Fit,
высота карты соответствует пропорциям картинки. Компактный экран прокручивается.
Фон карты остаётся дневным. Круглые миниатюры и грубая полигональная окантовка
убраны. Выбранное место выделяется лаймовым текстом и рамкой подписи.
Названия расположены под местами на тёмных плашках. Справа в верхней панели
размещена кнопка информации 52 dp. Нажатие открывает всплывающую подсказку
«Нажми на локацию, чтобы перейти в неё», закрываемую нажатием вне неё или Back.
По умолчанию подсказка скрыта и не перекрывает карту; её открытость хранится
через rememberSaveable. Все девять мест доступны; нажатие
на место или подпись переключает выделение. Каждое место и его подпись —
один крупный интерактивный элемент с единой областью нажатия и фокусом
доступности. Прямоугольные области приблизительно соответствуют размеру
локаций, без масок и точных контуров; координаты не задают правила игры.

В приложении все места доступны через `AllLocationsAvailable`.
Позже доступность будет зависеть от прохождения. Звуки вне текущего объёма.
День/вечер задаётся явно через `GameLocationController.setLighting`.
Усталость, энергия, часы и номер дня не меняют освещение (MAP-D-005).
Для города, ворот и мельницы добавлены сгенерированные вечерние WebP:
`location_city_evening`, `location_gates_evening`, `location_windmill_evening`.
[Исходники и промпты](assets/sources/location-evenings.md) сохранены отдельно.
Обсерватория уже имеет ночное изображение; для неё пока отсутствует дневное.
Превью не задаёт правила прохождения.

## Предложение вида закрытых мест

UI вынесен в `feature/map/ui`; это пакет фичи внутри `:app`, без нового
Gradle-модуля. `MapLocationUi.isUnlocked`
по умолчанию `true`. Экран получает доступность снаружи и не вычисляет её
из глав или истории.

Дополнительное Preview «Карта · закрытые локации» показывает выбранный город,
доступные мастерскую и причал и условно закрытые остальные места. Это
демонстрационные значения, не утверждённый порядок открытия. Основные
превью по-прежнему показывают все места доступными.

Предложение визуального оформления: закрытая подпись серая с замком,
доступная — белая, выбранная — лаймовая. Используется существующий
`customization_lock` из каталога. Нажатие на закрытое место открывает пояснение
о прохождении в сюжете и не вызывает callback выбора. Диалог закрывается
кнопкой «Понятно», Back или нажатием снаружи. Его состояние сохраняется
через rememberSaveable с ключом локации. Изменение доступности на открытую
скрывает пояснение. Точное оформление пока предложено для оценки в Preview.

## Программный интерфейс

`GameLocationController` внедряется через Hilt. Вызов из корутины:

```kotlin
controller.setLighting(LocationLighting.EVENING) // либо DAY
```

Освещение сохраняется независимо от локации; начальное значение DAY.
`selectLocation(GameLocation.PIER)` меняет место, сохраняя освещение.
Оба метода используют агрегатный `GameRepository.update` и актуальное состояние
в транзакции. Они не расходуют энергию, не меняют день, сюжет или ревизию движка.
`LocationAccessPolicy` проверяется при отображении и повторно внутри транзакции;
позже сюда подключается утверждённое соответствие сюжетного прогресса местам.
Сейчас такого соответствия нет и все места доступны.

При ошибке сохранения карта остаётся открытой и предлагает повторить выбор.
Повторные нажатия и выход во время записи блокируются. Возврат выполняется
после commit и только при RESUMED. Превью закрытых мест сохранено.
Меню и его размытые панели используют один resolver `locationArtwork`.
Обсерватория использует единственный существующий ночной ассет в обоих режимах;
это ограничение комплекта изображений, а не автоматическое правило освещения.
